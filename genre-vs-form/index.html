这两个词混用得非常普遍，但它们是两个独立的问题：

体裁（genre）曲式（form）
问的是做什么用（场合、编制、功能）怎么搭（结构安排）
例交响曲 · 小步舞曲 · 圣咏 · 练习曲奏鸣曲式 · 回旋曲式 · 变奏曲式
由谁决定用途与传统内部结构

一句话：体裁是"这是什么场合的音乐"，曲式是"它内部怎么组织"。

为什么这么容易混

因为一部分名称在两个维度上同时存在，而且历史上是同源的：

名称作为体裁作为曲式
奏鸣曲（sonata）一种多乐章器乐作品——
奏鸣曲式（sonata form）——一种单乐章结构
赋格（fugue）一种复调作品一种写法
变奏曲一种作品变奏曲式
卡农一种作品 / 段落的写法卡农曲式

"奏鸣曲式"这个名字，正是因为大量奏鸣曲的第一乐章用了这种结构才得名 —— 所以它俩的"同源"是真的，但不是同一件事。

说法正确理解
奏鸣曲的第一乐章常用奏鸣曲式但也可以用变奏曲式或回旋曲式（贝多芬就有这样的奏鸣曲）
赋格是一种写法它有对应的结构（见 [[concept:fugue-form
变奏曲是一种体裁它内部通常就是变奏曲式（见 [[concept:theme-variations
交响曲是体裁其第一乐章常用奏鸣曲式 —— 体裁决定了"用什么乐器和几个乐章"，曲式决定"每个乐章怎么搭"

第 1 行最有用：它说明体裁不限定曲式 —— 如果两者是同一件事，就不可能出现"用变奏曲式写的奏鸣曲第一乐章"。

为什么值得分清

分清之后得到什么
分析时不会把"这首是奏鸣曲"当成"这首是奏鸣曲式"
听辨时可以先问"这是什么用途的音乐"，再问"它内部怎么搭"
写作时体裁（编制 / 长度 / 场合）与曲式（结构）可以分别选择

图示：两个独立维度

听一听：同一结构，不同用途

用 progression 听同一组和声骨架。同一结构可以出现在任何体裁里 —— 圣咏、交响乐、流行歌都可能用它，但这不改变它是什么结构。

常见误解

  • 「奏鸣曲＝奏鸣曲式」 → 一个是体裁（多乐章作品），一个是曲式（单乐章结构）。大量奏鸣曲的乐章并不用奏鸣曲式。
  • 「名称相同就是同一件事」 → "奏鸣曲 / 奏鸣曲式"、"赋格 / 赋格曲式"、"变奏曲 / 变奏曲式"都是同源但不同维度。
  • 「体裁决定曲式」 → 体裁不限定曲式。同一种体裁可以用完全不同的结构。
  • 「分析曲式就够了，不必管体裁」 → 体裁决定了编制、长度期待与听者的预期，是分析的重要背景。

事实来源

  • 体裁由用途、场合与编制决定，曲式由结构安排决定，两者为独立维度，属曲式与体裁理论通则
  • "奏鸣曲 / 奏鸣曲式""赋格 / 赋格曲式"等名称的历史沿革，为音乐史通行表述
