演奏法记号

它决定音与音"怎么连接"——与"多响"是两个维度

约 3 分钟912 字条目记谱法更新 2026-09-25

演奏法记号管的是一个独立维度：音与音之间怎么连接。它不负责音有多响，那是 力度记号 的事。

它决定音与音之间怎么连接，与响度无关。

基本记号

记号名称效果
圆滑线（弧线）连奏（legato）音之间不断开
·（点）断奏（staccato）音明显分开，但保留部分时值
▾（尖点）顿音（staccatissimo）更短的断奏
—（短横）保持音（tenuto）时值拉满，略强调
>（楔形）重音（accent）瞬间加强
^强跳音（marcato）短且强

注意：>（重音）与渐弱记号外形相近，含义却完全不同。渐弱属于 力度记号 的范围。

它在不同乐器上的名称

同一件事，不同乐器有各自的叫法。

乐器术语说明
弦乐弓法连弓（一弓多音）/ 分弓（一弓一音）/ 顿弓 / 跳弓
管乐吐音单吐 / 双吐 / 三吐 —— 用舌头的不同动作控制音头
键盘触键方式手指的离键高度与速度
声乐咬字与连断与歌词音节配合

所以"演奏法"是跨乐器的通用概念。弓法、吐音只是它在具体乐器上的实现方式。

为什么它值得单列

同一串音，换一种演奏法就是另一种性格。

同一串音连奏断奏
听感歌唱、连贯、抒情轻快、颗粒感、生机
常见场合慢乐章、旋律主题谐谑曲、舞曲、快速段落

这与"改节奏型就改性格"是同一类现象（见 节奏型）。音高和时值都没变，性格却完全不同。演奏法因此是独立的表达维度，不是音高与时值的附属。

一个历史要点

演奏法记号的实际处理也随时代变化。这一点与力度记号相同（见 力度记号）。

时期情况
巴洛克标记较少；连断处理常需从乐器特性与时代惯例推断
古典标记逐渐细化，但仍有大量惯例（如"不标圆滑线时的默认连断"）
浪漫以后标记极其详尽

所以"照谱面直译"往往不是正确读法。巴洛克段落不标圆滑线，并不意味着要断奏。连断方式要看当时的惯例（见 历史演奏法）。

听一听：连奏与断奏的性格

用 rhythm 组件对比两种时值形态。后面的"留白"相当于断奏，音与音之间出现空隙。听的时候请留意，性格会立刻改变。

常见误解

  • 「演奏法是"小细节"」 → 它是独立的表达维度，换演奏法性格就变。
  • 「不标圆滑线就是断奏」 → 巴洛克连断看时代惯例，照谱直译会错。
  • 「断奏就是把音弹短」 → 断奏是分开音、保留时值，极短的是顿音。
  • 「重音记号与渐弱记号差不多」 → 完全不同，> 瞬间强调，渐弱是渐次下降。
