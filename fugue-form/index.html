赋格曲式

赋格的结构：呈示段 → 中间段 → 结束段——它有自己的段落逻辑

约 2 分钟731 字条目曲式更新 2026-09-25

相关

赋格曲式模仿奏鸣曲式持续低音

与 赋格（写法） 的分工很明确。

T6 的「赋格」讲写法：主题如何进入、如何交织。 本条讲结构：把这种写法组织成整曲时，段落怎么安排。

三段的段落逻辑

段内容常见手法
呈示段各声部依次进入，把主题交代完主题 → 答题（属调）→ 主题 → 答题
中间段主题继续出现，但调性不断游移间插段（用主题片段模进，见 模进）+ 各调上的进入
结束段主题回到主调，收束密接和应（进入互相交叠）+ 持续音（见 持续低音）+ 尾声

三段的划分依据与奏鸣曲式不同。奏鸣曲式靠调性对比，第二主题在属调。赋格靠主题进入的密集程度与调性距离。没有第二主题，只有同一个主题在不同调上反复出现。

与奏鸣曲式的对照

两者都属于"呈示—展开—回归"的大家族，机制却有别。

奏鸣曲式赋格曲式
对比靠什么两个主题 + 两个调同一主题 + 密集度与调性距离
"展开"的手段把素材拆开（片段化）把主题移位（各调进入）+ 间插段
回归的标志第二主题回主调（调性统一）主题回主调 + 密接和应
收束手段终止式持续音 + 终止式

奏鸣曲式用两个东西制造张力。赋格用同一个东西的不同处境制造张力。

听一听：回归与收束

用 progression 听一段"离开主调、再回到主调"的进行。赋格结束段的收束感与此同源。主题在各调游移之后回到主调，那份"回家"的感觉就是结构完成的标志。

常见误解

  • 「赋格是固定曲式，段落数量固定」 → 段落逻辑存在，但数量与长度高度自由。二声部小赋格可能只有呈示段加一个间插段。
  • 「赋格没有段落划分」 → 恰恰相反。它有清楚的三段逻辑，分界靠主题进入的密集程度，不靠终止式。
  • 「赋格必须四个声部」 → 二到五声部都有（见 赋格）。
  • 「赋格曲式就是奏鸣曲式的复调版」 → 家族相似，机制不同。一个靠调性对比，一个靠素材层叠。
